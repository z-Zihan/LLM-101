# AI 概念速查表

> 这不是第三条学习路线，也不替代正文。它只解决一个问题：**看到一个词时，先把它放回正确层次，再进入唯一主页面。**

如果你是第一次系统学习，请从 [README 主路线](../../README.md#主学习路线)开始；如果你脑中已有具体问题，请用[真实问题矩阵](../../真实问题矩阵.md)。速查表适合忘记边界时回来定位。

## 领域、方法、模型与产品

| 词 | 一句话定位 | 最容易混淆 | 深入阅读 |
|---|---|---|---|
| AI | 围绕目标处理输入并产生预测、内容、建议或行动的广泛领域 | 不等于 LLM | [AI 到底是什么](../01-AI与大模型/01-AI到底是什么.md) |
| 机器学习 | 从数据中调整模型，而不是写死每条规则的方法 | 不是一个具体模型 | [AI、机器学习和深度学习](../01-AI与大模型/02-AI机器学习和深度学习是什么关系.md) |
| 深度学习 | 主要使用多层神经网络学习表示的一类机器学习方法 | 不是所有 AI | [AI、机器学习和深度学习](../01-AI与大模型/02-AI机器学习和深度学习是什么关系.md) |
| 生成式 AI | 生成文本、图像、音频、代码等内容的模型和技术 | AIGC 是内容/产业语境 | [弱 AI、生成式 AI 和 AIGC](../01-AI与大模型/06-弱AI生成式AI和AIGC有什么区别.md) |
| 模型 | 训练后确定下来的输入到输出计算关系 | 不等于产品、算法或数据 | [模型到底是什么](../01-AI与大模型/03-模型到底是什么.md) |
| 语言模型 | 对语言序列及后续 Token 的可能性建模 | 不一定是“大”模型 | [大语言模型是什么](../01-AI与大模型/04-什么是大语言模型.md) |
| LLM | 用大量数据和计算训练的大规模语言模型 | 不等于聊天产品 | [大语言模型是什么](../01-AI与大模型/04-什么是大语言模型.md) |
| GPT | 一类生成式预训练 Transformer 模型家族名称 | ChatGPT 是产品 | [GPT 和 ChatGPT](../01-AI与大模型/05-GPT和ChatGPT有什么区别.md) |

## 从数据到一个可运行模型

| 词 | 一句话定位 | 最容易混淆 | 深入阅读 |
|---|---|---|---|
| 架构 | 规定组件、连接和信息流的结构设计 | 不是训练后的权重 | [模型架构是什么](../03-模型原理与训练/02-模型架构是什么.md) |
| Transformer | 以注意力等模块处理序列的一类架构 | 不等于全部 LLM 能力 | [Transformer 到底是什么](../03-模型原理与训练/03-Transformer到底是什么.md) |
| Attention | 根据当前计算需要为不同位置分配影响权重 | 不是“模型只关注关键词” | [Attention 到底是什么](../03-模型原理与训练/05-Attention到底是什么.md) |
| 参数 | 训练会调整、推理会使用的内部数值 | 参数量不是数据量 | [参数到底是什么](../03-模型原理与训练/06-参数到底是什么.md) |
| 训练数据 | 用来提供输入、目标或学习信号的样本 | 不会逐条变成参数格子 | [参数量和训练数据](../03-模型原理与训练/07-参数量和训练数据有什么区别.md) |
| 训练 | 根据目标和误差更新参数的过程 | 不等于日常聊天 | [训练和推理](../03-模型原理与训练/18-训练和推理有什么区别.md) |
| 推理（Inference） | 用固定参数处理当前输入并计算输出 | 不一定需要逻辑推理 | [训练和推理](../03-模型原理与训练/18-训练和推理有什么区别.md) |
| Checkpoint / 权重文件 | 把参数及必要状态保存到磁盘的产物 | 文件不等于完整产品 | [safetensors 和 GGUF](../03-模型原理与训练/09-safetensors和GGUF是什么.md) |
| 量化 | 用更少位数近似权重或其他数值 | 不减少参数个数 | [剪枝、量化和蒸馏](../03-模型原理与训练/13-剪枝量化和蒸馏有什么区别.md) |
| 剪枝 | 屏蔽权重或移除结构以形成稀疏/更小计算图 | 置零不保证加速 | [剪枝、量化和蒸馏](../03-模型原理与训练/13-剪枝量化和蒸馏有什么区别.md) |
| 蒸馏 | 训练学生模型学习教师输出或表示 | 不是修改数值位宽 | [剪枝、量化和蒸馏](../03-模型原理与训练/13-剪枝量化和蒸馏有什么区别.md) |

## 一次对话里发生什么

| 词 | 一句话定位 | 最容易混淆 | 深入阅读 |
|---|---|---|---|
| Prompt | 当前提供给模型的任务与约束输入 | 不会自动改权重 | [Prompt 到底是什么](../02-聊天Token与上下文/01-Prompt到底是什么.md) |
| System Prompt | 平台或应用提供的一类高优先级运行时输入 | 不是无法被攻击的权限系统 | [System Prompt 是什么](../02-聊天Token与上下文/02-System-Prompt是什么.md) |
| Token | Tokenizer 编码和模型生成时处理的离散单位 | 不固定等于一个字或单词 | [Token 到底是什么](../02-聊天Token与上下文/04-Token到底是什么.md) |
| 上下文 | 当前一次计算中模型实际可使用的信息 | 不等于长期记忆 | [上下文和上下文窗口](../02-聊天Token与上下文/07-上下文和上下文窗口是什么.md) |
| 上下文窗口 | 一次输入与输出可容纳内容的容量边界 | 长窗口不保证有效使用 | [上下文和上下文窗口](../02-聊天Token与上下文/07-上下文和上下文窗口是什么.md) |
| 聊天记录 | 产品保存的历史消息 | 保存不等于本轮已放进上下文 | [聊天记录是什么](../12-Memory/01-聊天记录是什么.md) |
| 泛化 | 把训练中学到的模式用于未参与训练的新样本 | 不能靠一次新问法证明 | [泛化是什么](../04-模型能力/01-泛化是什么.md) |
| 训练数据记忆 | 对具体训练片段异常高概率或逐字复现 | 和泛化可以同时存在 | [记忆训练数据和泛化](../04-模型能力/02-记忆训练数据和泛化有什么区别.md) |
| 推理能力（Reasoning） | 在任务中组合信息、遵守约束并推进到结论 | 与 Inference 同译但含义不同 | [推理能力是什么](../04-模型能力/03-推理能力是什么.md) |
| 幻觉 | 输出看似合理却与事实或给定资料不一致 | 联网也不能自动消除 | [幻觉是什么](../05-幻觉与模型局限/01-幻觉是什么.md) |

## 外部知识与行动能力

| 词 | 一句话定位 | 最容易混淆 | 深入阅读 |
|---|---|---|---|
| API | 程序之间约定请求与响应的接口 | 不专属于 AI | [API 到底是什么](../06-工具与Function-Calling/01-API到底是什么.md) |
| Tool | 由宿主真实执行并返回结果的一项外部能力 | 模型只能请求，不能凭 JSON 执行 | [AI 工具到底是什么](../06-工具与Function-Calling/02-AI工具到底是什么.md) |
| Function Calling | 模型按函数名和参数结构表达工具请求的机制 | 不等于工具已经成功执行 | [Function Calling 是什么](../06-工具与Function-Calling/03-Function-Calling是什么.md) |
| RAG | 先检索，再把候选资料放入上下文辅助生成 | 不修改底座参数 | [RAG 到底是什么](../08-RAG与知识库/01-RAG到底是什么.md) |
| Embedding | 把对象映射成便于相似性计算的向量 | 不是原文或答案 | [Embedding 是什么](../08-RAG与知识库/03-Embedding是什么.md) |
| 向量数据库 | 保存、索引和过滤向量以支持相似检索 | 不等于知识图谱 | [向量数据库是什么](../08-RAG与知识库/05-向量数据库是什么.md) |
| 知识图谱 | 用实体、关系和属性组织可查询事实 | 不是语义相似性索引 | [知识图谱和向量数据库](../08-RAG与知识库/06-知识图谱和向量数据库有什么区别.md) |
| MCP | 让 AI 应用统一连接工具、资源和提示模板的协议 | 不是 Agent 或模型 | [MCP 到底是什么](../09-MCP/01-MCP到底是什么.md) |

## Agent 与产品协作

| 词 | 一句话定位 | 最容易混淆 | 深入阅读 |
|---|---|---|---|
| Workflow | 主要路径和分支由程序预先规定的自动化流程 | 不需要开放式决策循环 | [Workflow 和 Agent](../07-Agent/05-Workflow和Agent有什么区别.md) |
| Agent | 围绕目标读取状态、选择行动、观察结果并继续的系统 | 不等于一个会聊天的模型 | [Agent 到底是什么](../07-Agent/01-Agent到底是什么.md) |
| Agent Loop | 目标 → 决策 → 行动 → 观察 → 更新状态的循环 | 没有停止边界会失控 | [Agent Loop 是什么](../07-Agent/03-Agent-Loop是什么.md) |
| ReAct | 把推理、行动和环境观察交替组织的方式 | 不等于多分支搜索 | [思维树、思维链和 ReAct](../04-模型能力/06-思维树思维链和ReAct有什么区别.md) |
| Tree of Thoughts | 生成、评估并搜索多个部分状态的推理时编排 | 不是一句“多想想”Prompt | [思维树、思维链和 ReAct](../04-模型能力/06-思维树思维链和ReAct有什么区别.md) |
| Copilot | 强调用户持续掌舵、AI 提供建议或局部行动的产品定位 | 某些模式也可能有 Agent 能力 | [从 AI Embedded、Copilot 到 Agent](../07-Agent/07-从AI-Embedded和Copilot到Agent.md) |
| Skill | 可按需加载的任务方法、脚本与参考资料能力包 | 不等于外部执行 Tool | [Skill 到底是什么](../10-Skill/01-Skill到底是什么.md) |
| Coding Agent | 面向代码仓库使用模型、工具、状态和验证循环的 Agent | 不等于代码补全 | [Coding Agent 是什么](../11-Coding-Agent/04-Coding-Agent是什么.md) |
