# AI、ML、DL 到底什么关系？

> Level: `Core`

## 读完你应该明白

1. AI、机器学习和深度学习不是三个并列概念。
2. 它们的范围关系是：`深度学习 ⊂ 机器学习 ⊂ AI`。
3. 机器学习从数据中学习规律，深度学习主要使用多层神经网络。
4. “深度”不代表意识更深，也不保证在所有任务上更好。

## 一个小白真的会怎么问？

> AI、机器学习、深度学习，是同一件事的三个名字吗？
>
> 现在的 AI 是不是全都靠深度学习？

聊天记录没有直接提出这组问题，因此这里采用自然的小白问法。

## 先说人话

这三个概念像三个从大到小的盒子：

```text
┌──────────────────────── AI ────────────────────────┐
│  规则、搜索、规划……                                │
│                                                    │
│  ┌──────────── Machine Learning（ML）───────────┐  │
│  │  决策树、线性模型……                         │  │
│  │                                              │  │
│  │  ┌────── Deep Learning（DL）──────────────┐  │  │
│  │  │  多层神经网络                          │  │  │
│  │  └────────────────────────────────────────┘  │  │
│  └──────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────┘
```

因此：

> **深度学习是机器学习的一部分，机器学习又是 AI 的一部分。**

## 举个例子：怎么判断垃圾邮件？

假设我们要让电脑判断一封邮件是不是垃圾邮件。

### 做法一：人工规则

人可以写规则：

```text
如果标题包含“免费中奖”
并且发件人不在联系人中
那么提高垃圾邮件分数
```

这个系统可以属于 AI，但它没有从数据中自动学出规则，所以不一定属于机器学习。

### 做法二：机器学习

我们给系统许多已经标明“垃圾 / 正常”的邮件。训练方法从数据中找出哪些文字、发件方式和格式与垃圾邮件有关，再得到一个用于判断新邮件的模型。

这属于机器学习。

### 做法三：深度学习

我们也可以用一个具有许多计算层的神经网络，让它逐层形成对文字和邮件结构的表示，再完成判断。

这既属于深度学习，也属于机器学习和 AI。

## 严格来说

### 什么是 AI？

人工智能（Artificial Intelligence，AI）是最大的范围：研究和构建能执行感知、语言、预测、判断、规划等任务的机器系统。

完整解释见：[AI 是什么](./01-what-is-ai.md)。

### 什么是机器学习？

机器学习（Machine Learning，ML）是一类让计算机**利用数据或经验改善某项任务表现**的方法。

传统程序通常由人明确写下处理规则：

```text
人写规则 + 输入
        ↓
      输出
```

机器学习则让训练方法从示例数据中调整模型：

```text
训练数据 + 学习方法
        ↓
      模型
        ↓
   新输入 → 输出
```

这里的“学习”是技术用语，表示系统的任务表现能利用数据或经验得到改善。它不自动表示系统像人一样理解或拥有意识。

### 什么是深度学习？

深度学习（Deep Learning，DL）是机器学习的一类方法，主要使用具有多层计算结构的神经网络，从数据中学习不同层次的表示。

“神经网络”是一种受生物神经系统启发、但用数学和计算实现的模型。它不是人脑的复制品。

“深度”主要指模型中有多层表示和计算，不是说它的思想、意识或理解“更深”。

## 为什么要分成这三层？

AI 最初就包含多种路线。面对一个任务，研究者可以：

- 把知识写成规则；
- 在许多方案中搜索；
- 规划一连串动作；
- 让系统从数据中学习。

当现实问题复杂到无法手写所有规则时，机器学习变得非常有用。

但是，传统机器学习往往还需要人先决定应当从原始数据中提取哪些特征。比如识别图片时，人可能先设计“边缘”“颜色”等特征。

深度学习进一步尝试让多层网络从原始数据中学习适合任务的表示：

```text
原始输入
  ↓
较简单的表示
  ↓
更抽象的表示
  ↓
任务输出
```

上图只是帮助理解层次关系，不表示每一层都能被人直接命名，也不表示所有深度学习模型都按完全相同的方式工作。

## 最容易搞混的东西

### AI、ML、DL 不是三个开发步骤

不是先“做 AI”，再做 ML，最后做 DL。

它们描述的是概念范围。选择深度学习，就已经同时处在机器学习和 AI 的范围内。

### 机器学习不等于深度学习

决策树、线性模型等也能从数据中学习，但通常不叫深度学习。

```text
机器学习
├── 线性模型
├── 决策树
├── 其他传统方法
└── 深度学习
```

### AI 产品不等于单一模型

一个真实产品可能同时使用：

- 人工规则；
- 传统机器学习模型；
- 深度学习模型；
- 数据库和普通业务代码。

因此，不要因为产品宣传“使用 AI”，就假设它内部只有一个深度学习模型。

### 深度学习不等于大语言模型

大语言模型通常使用深度学习，但深度学习还可以用于图像、语音和许多其他任务。

```text
深度学习
├── 图像模型
├── 语音模型
├── 大语言模型
└── 其他模型
```

## 常见误区

### 误区 1：现在所有 AI 都是深度学习

不对。深度学习非常重要，但现实系统仍会使用规则、搜索、规划、传统机器学习和普通软件。很多产品是这些部分的组合。

### 误区 2：深度学习一定比传统方法好

不对。选择方法要看任务、数据量、成本、可解释性和运行环境。对于一些结构清晰、数据有限的问题，较简单的方法可能更合适。

### 误区 3：神经网络就是电子大脑

这只是容易产生误导的类比。神经网络借用了“神经元”等名称，但它实际是由数学运算和可调整数值构成的计算模型。

## 为什么我要知道它？

以后你会经常看到这些句子：

- “这家公司做 AI。”
- “这个功能用了机器学习。”
- “这个模型基于深度学习。”
- “LLM 是一种模型。”

如果不先分清范围，就容易把一个行业、一个方法、一类模型和一个产品当成同一件事。

记住包含关系以后，你就能继续追问更有用的问题：

> 它解决什么任务？使用什么数据？训练出了什么模型？这个模型如何进入产品？

## 它和前后知识是什么关系？

```text
AI：最大的目标和方法范围
 ↓
ML：从数据中学习规律的一类方法
 ↓
DL：使用多层神经网络的一类 ML 方法
 ↓
Model：训练后用来处理新输入的计算关系
 ↓
LLM：主要处理语言的一类大型模型
```

## 你只需要记住

1. `Deep Learning ⊂ Machine Learning ⊂ AI`。
2. 机器学习从数据或经验中改善任务表现，不要求人写出每一条判断规则。
3. 深度学习主要使用多层神经网络；“深”不代表有更深的意识。
4. 实际 AI 产品经常混合规则、ML、DL 和普通软件。
