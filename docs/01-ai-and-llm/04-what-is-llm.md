# 什么是大语言模型 LLM？

> Level: `Core` · Path: `Main`

## 读完你应该明白

1. 语言模型是在对语言中的序列规律建模。
2. LLM 是大规模的语言模型，不是 AI 的全部。
3. “Large”没有一个永久统一的参数门槛。
4. LLM 的流畅回答不等于事实一定正确。

## 一个小白真的会怎么问？

> 大语言模型到底“大”在哪里？
>
> LLM 和 AI、聊天机器人是不是同一个东西？

## 先说人话

大语言模型（Large Language Model，LLM）可以先理解成：**通过大量语言数据训练出来、能够处理和生成语言的大型模型。**

它读入一段内容后，可以根据训练中学到的语言规律，计算接下来什么内容更可能出现。

## 先理解“语言模型”

一句话可能有很多接法：

```text
今天天气很____
          ↓
       好 / 冷 / 热 / 糟糕……
```

语言模型（Language Model）会给不同接法分配可能性。现代自回归语言模型生成文本时，会反复预测下一个 Token——Token 是模型处理文本时使用的文本单元，后文会单独解释。

```text
已有 Token
   ↓
预测下一个 Token 的可能性
   ↓
选出一个 Token
   ↓
把它接回已有内容，继续预测
```

所以，LLM 不是从数据库里直接取出一整段固定答案；它通常是在当前输入后逐步生成输出。

## “Large”到底大在哪里？

通常包含几个方面：

- 模型中有大量可训练参数；
- 使用大规模、多来源的语言数据训练；
- 训练和运行需要较多计算资源；
- 能在同一个模型中处理较广泛的语言任务。

但是，“超过多少参数才算 LLM”没有全球统一且永久不变的门槛。随着技术发展，同样的参数规模在不同年代可能被称为“大型”或“小型”。

因此，更稳妥的理解是：`Large` 描述的是相对于同类语言模型的规模与训练范围，不是一张固定合格证。

## 严格来说

LLM 通常指使用深度神经网络、在大规模文本或相关数据上训练的语言模型。它从语言序列中学习统计结构，并能根据输入计算和生成后续序列。

许多现代 LLM 使用 Transformer 架构。Transformer 是一种规定信息如何流动和计算的模型架构；它不是 LLM 的同义词，也可以用于语言之外的任务。

LLM 的训练目标、数据和后训练方式可能不同，所以“都是 LLM”不代表能力、行为或安全边界完全相同。

## 为什么预测下一个 Token 能做很多事？

要在不同上下文中持续预测得更好，模型必须捕捉许多规律，例如：

- 词语和句子的搭配；
- 不同写作形式；
- 文本中呈现的事实关联；
- 问题与回答的常见结构；
- 代码和自然语言中的模式。

训练规模扩大后，同一个模型可以通过不同输入方式完成续写、摘要、翻译、问答和代码生成等任务。

但这只是第一层解释。为什么预测任务能形成这些能力、哪些属于记忆或泛化，后面的“下一个 Token”与“模型能力”文章会继续展开。

## 为什么需要大语言模型？

过去常为每个语言任务训练一个专用系统：一个做分类，一个做翻译，另一个做摘要。

大规模预训练带来另一条路线：

```text
先在广泛语言数据上学习通用规律
              ↓
得到可处理多种语言任务的基础能力
              ↓
再通过提示、后训练或工具适配具体用途
```

这样，一个模型可以成为许多语言应用的共同基础。

## 最容易搞混的东西

### LLM ≠ AI

AI 是更大的领域。LLM 是 AI 中一类主要处理语言的模型。

### LLM ≠ 聊天产品

聊天产品通常由模型、界面、服务器、安全规则、搜索和其他工具共同组成。LLM 只是其中的核心部件之一。

### LLM ≠ Transformer

Transformer 是架构；LLM 是按任务、规模和训练方式描述的一类语言模型。两者关系密切，但不是同一个概念。

### LLM ≠ 数据库

数据库按明确结构保存和查询记录。LLM 通过参数共同实现的计算关系生成输出，不能保证逐条准确取回事实。

### LLM 与 Foundation Model

基础模型（Foundation Model）强调一个模型在广泛数据上训练后，可以适配许多下游任务。很多 LLM 同时是基础模型，但基础模型也可以主要处理图像、音频等其他数据。

## 常见误区

### 误区 1：模型越大，回答就一定越正确

规模只是影响能力的因素之一。数据、架构、训练方法、后训练、工具和具体任务都会影响结果。

### 误区 2：能流畅聊天，就等于具有人类理解

流畅输出说明模型能有效处理语言模式，不能仅凭这一点证明它拥有人的意识或主观体验。

### 误区 3：LLM 记得互联网上的每一句话

模型可能记住部分训练片段，但它不是训练资料的可查询副本。它也会混淆、遗漏或生成错误内容。

## 为什么我要知道它？

理解 LLM 后，你才能继续区分：

- 模型和聊天产品；
- GPT 和 ChatGPT；
- 训练时学到的参数与聊天时提供的 Context；
- 模型自身能力与搜索、RAG、Tool、Agent 带来的系统能力。

## 它和前后知识是什么关系？

```text
AI
 ↓
Machine Learning
 ↓
Deep Learning
 ↓
Model
 ↓
Language Model
 ↓
LLM
 ↓
具体模型家族与聊天产品
```

## 你只需要记住

1. 语言模型对语言序列中的可能性进行建模。
2. LLM 是大规模训练的现代语言模型，不是 AI 的全部。
3. “Large”没有固定不变的参数门槛。
4. LLM 通常逐 Token 生成内容，流畅不等于事实一定正确。
