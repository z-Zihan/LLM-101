# 涌现能力是什么？

把模型从 7B 扩到 70B 后，某项能力会不会像开关一样突然出现？研究中常把随着模型规模增加、在较小模型上接近缺失而在较大模型上明显出现的任务表现称为涌现能力（Emergent Ability）。

这个说法描述的是一组测量现象，不证明模型内部在某个精确参数量发生了神秘相变。判断是否“突然”，高度依赖横轴选什么规模、纵轴用什么指标、采样点多密以及模型是否经过不同后训练。

## 平滑能力为什么会测成台阶

设一道题要求最终答案完全正确。小模型从 20% 提升到 49%，大模型从 49% 提升到 51%；如果评分只记“是否超过 50%”，图上就会从失败突然跳到成功。若改用每个步骤的概率、校准分数或连续误差，底层改善可能更平滑。

```text
模型内部可用信号：  ▁▂▃▄▅▆▇  逐渐增强
离散 Benchmark：    0 0 0 0 1 1 1  看起来突变
```

Schaeffer 等人的研究表明，一些被报告为涌现的结果会随指标选择而出现或消失。这不等于所有非线性增长都是测量幻觉；它说明“曲线突然上升”必须接受指标敏感性检查。

检查时至少要看：

- 用连续指标替换精确匹配后，跳变是否仍存在；
- 增加中间规模和多个随机种子后，曲线是否稳定；
- 任务是否有最低可用阈值，例如代码只有全部语法正确才运行；
- 测试集是否污染，Prompt 和解码设置是否一致。

## 后训练可能把“会”与“能展示”混在一起

预训练模型可能已经形成某些潜在表示，却不擅长按指令输出；监督微调、偏好优化或工具格式训练能显著改变可测表现。若较小模型测基础版本、较大模型测聊天版本，就无法把差异只归因于参数规模。

即使所有模型都做后训练，数据量、配方和教师模型也可能随规模变化。此时观察到的是“规模 + 数据 + 训练流程”的联合结果。严谨报告应尽量控制训练条件，并分别测试基础模型与后训练模型。

所谓“能力解锁”也要小心。后训练可能只是让已有能力更容易被 Prompt 触发，也可能真的教会新格式或新策略；没有对照实验，不能只凭最终 Benchmark 区分两者。

## In-Context Learning 与涌现是什么关系

In-Context Learning（上下文学习）指模型在当前 Prompt 中根据示例改变后续行为，而不更新参数。有研究提出，某些跨任务的涌现曲线可能来自模型逐渐具备更强的上下文学习能力：规模扩大后，它更能从题目示例识别任务，许多下游分数便一起改善。

这是一种解释，不是所有涌现现象的统一答案。模型也可能通过更好的表示、记忆、组合泛化或优化稳定性提升。验证关系需要改变示例数量、示例质量和任务说明，观察能力是否随上下文支持而系统变化。

## 能否提前预测阈值

预测困难有三层原因。第一，很多指标本身离散且带噪；第二，模型家族之间不只参数量不同，数据、架构和后训练也不同；第三，研究者通常只有少数昂贵规模点，恰好缺少阈值附近的密集观测。

拟合小模型趋势再外推到大模型，可能低估真正的非线性，也可能把噪声夸大成断点。更稳妥的做法是给出区间和不确定性，提前声明指标，在多个模型家族上复现，并寻找比最终正确率更早出现的连续代理信号。

“不可精确预测”不等于完全不可研究。训练 Loss、过程指标、可校准概率和能力组成部分都能提供预警；只是不能承诺“到 37B 参数一定出现某能力”。

## 什么现象才配叫涌现

在宽松用法里，只要能力随规模明显出现就会被称为涌现；在严格研究中，还应满足更高门槛：

1. 小规模表现接近某个明确定义的基线；
2. 跨过一段规模区间后出现显著、可复现的非线性改善；
3. 结果不只由离散指标、Prompt 变化、污染或后训练差异造成；
4. 在合理替代指标和多个模型家族上仍有证据。

是否使用“涌现”这个词不如把测量条件写清重要。对产品团队而言，更直接的问题是能力在自己的任务上是否可靠、失败边界在哪里、成本是否可接受。

## 回答五个真实追问

**涌现是真的突然，还是评分造成的？** 两种情况都可能。必须用连续指标、密集规模点和控制变量区分，不能从一条台阶曲线直接下结论。

**能否预测哪种能力在什么规模出现？** 可以估趋势和区间，很难给跨模型通用的精确参数阈值。

**看到的是规模涌现还是后训练解锁？** 若基础模型、数据和后训练配方没有对照，就无法拆开；应分别测预训练与后训练版本。

**涌现与 In-Context Learning 有什么关系？** 更强的上下文学习可能解释部分任务的共同跃升，但不是所有现象的唯一机制。

**“跨过阈值”有多严格？** 严格证据要排除指标离散、采样稀疏、污染和训练配方变化，并在替代测量下复现。
