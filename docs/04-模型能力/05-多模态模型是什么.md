# 多模态模型是什么？

> 所属专题：[大语言模型](../01-AI与大模型/04-什么是大语言模型.md) · [Token](../02-聊天Token与上下文/04-Token到底是什么.md) · [泛化](./01-泛化是什么.md)
>

多模态模型处理不止一种信息形式，例如文本、图像、音频或视频。它“看图”时通常不会把原始 JPEG 永久存进语言模型参数，而是由视觉编码器把像素转换成一组连续向量，再通过连接模块交给后续模型计算。

不同产品都能接收图片，不代表内部架构相同。有的模型用独立视觉编码器加语言模型，有的从更早阶段联合训练；有的把视觉表示接成类似 Token 的序列，有的通过 Cross-Attention 读取视觉特征。

## 图片怎样变成模型可以计算的表示

常见视觉 Transformer 会把图像分成小块（Patch），把每块像素投影成向量，并加入位置表示。经过多层视觉编码后，得到一组携带图像信息的特征。

```text
图片像素
  ↓ 分块与视觉编码
视觉特征序列
  ↓ Connector / Q-Former / Cross-Attention
语言模型可使用的表示
  ↓
生成文本或执行其他任务
```

这些视觉向量常被产品文档称为 Visual Token，因为它们像文本 Token 一样占用序列位置或计算预算。但两者并不相同：文本 Token 先是词表中的离散 ID，视觉 Token 通常来自图像区域的连续特征；它们的编码器、位置结构和信息密度也不同。

连接模块要解决维度和分布不匹配。一个线性层或 MLP 可以把视觉特征投影到语言模型隐藏维度；更复杂的 Q-Former 使用一组可学习 Query，从大量视觉特征中提取固定数量的表示；Cross-Attention 则让语言侧在需要时读取视觉侧。

## CLIP 学的是对齐，不是直接写长答案

CLIP 使用图像—文本对做对比学习：匹配的图片与文本表示应更接近，Batch 中其他组合通常作为负样本。它适合零样本分类、图文检索和提供视觉表示，但单独的双编码器并不会像自回归 LLM 一样逐 Token 生成长回答。

把视觉特征连接给 LLM 的生成式模型，目标是让语言模型根据图像和文本上下文生成输出。两条路线可以组合：先用对比学习得到强视觉编码器，再训练 Connector 和语言模型完成描述或问答。

Batch 内负样本并不保证语义真的相反。两张不同图片都可能是“海边的狗”，于是互相成为假负样本。更大、更干净的配对数据，多正例设计、去重、软标签或其他对比目标能缓解问题，但无法仅靠扩大 Batch 自动消除。

## 为什么有的模型用 Q-Former，有的只用 MLP

Q-Former 能通过少量可学习 Query 压缩和选择视觉信息，在冻结的大视觉编码器与语言模型之间建立较强适配。简单 MLP 参数少、实现直接，若视觉编码器特征已经好、训练数据足够、语言模型能有效接收视觉序列，也可能达到很强效果。

选择取决于视觉特征长度、训练预算、是否冻结两侧模型、任务对细节的要求和延迟约束。“模块更复杂”不自动表示效果更好；简单 Connector 也可能把更多负担交给数据和后续训练。

## 空间、数量与遮挡为什么仍然难

识别“图里有一辆车”与回答“第三辆车在红色路牌左侧吗”不是同一难度。分块和压缩可能丢失细粒度位置；训练描述常强调显著物体而不是精确坐标；语言模型又容易根据常见场景补全。

计数还需要区分相似实例并保持一一对应，遮挡会让局部证据不完整，左右关系可能受相机视角和图像旋转影响。提高图像分辨率、保留区域特征、加入检测或 OCR 工具、专门空间数据和可验证中间表示都可能有帮助，但应在目标场景实测。

## 多模态幻觉可能来自整条链

模型把不存在的物体说出来，原因可能不同：

- 视觉编码器没有保留关键细节；
- Connector 对齐不足，让视觉信号难以被语言模型使用；
- 训练答案带偏或图文配对噪声大；
- 语言模型先验压过了弱视觉证据；
- 解码和 Prompt 鼓励猜测而非表达不确定。

只调一句“请看仔细”无法定位问题。可以分别测视觉分类或检测、图文对齐、带证据问答和最终生成；对高风险任务加入区域引用、OCR/检测工具、拒答阈值和人工复核。

## 没见过的新物体怎样描述

模型可能根据颜色、形状、材质和部件等视觉特征组合出描述，再借语言知识寻找近似概念。这是泛化，不等于它已经知道准确商品型号。若系统另接商品库检索，才可能根据图像相似度返回可追溯记录。

“识别类别”“描述属性”和“查询身份”要分开评测。看到陌生设备时说“像带旋钮的测量仪”可能合理；断言具体品牌与型号则需要标签、检索或其他证据。

## 回答八个真实追问

**模型看见的是图片还是视觉 Token？** 常见架构先把像素编码为视觉特征；原图仍可由外部系统保存，但语言模型主要计算这些表示。

**视觉 Token 与文字 Token 相同吗？** 不同。它们可进入共同序列或隐藏空间，却有不同来源、编码方式和信息结构。

**为什么空间、遮挡和计数容易错？** 这些任务需要保留细粒度位置、实例对应和不完整证据，普通图文训练不一定充分监督。

**CLIP 的假负样本怎么办？** 使用更好的数据、多个正例、去重、软目标或改进损失；Batch 中“其他样本都是负例”只是一种近似。

**对比学习与接 LLM 生成有什么区别？** 前者主要学习跨模态相似空间，后者让模型基于视觉表示生成序列，目标和输出形式不同。

**Q-Former 为什么可被 MLP 替代？** 两者都承担模态连接；简单投影在强特征和足够训练下可能有效，Q-Former则显式选择和压缩。

**多模态幻觉来自哪里？** 视觉、连接、数据、语言先验和解码都可能贡献，需要分阶段诊断。

**新商品是识别、检索还是泛化？** 三者都可能，但保证不同；没有外部目录时，通常只能基于视觉特征和语言知识描述或猜测。
