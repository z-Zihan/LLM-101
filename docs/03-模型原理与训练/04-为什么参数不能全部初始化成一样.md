# 为什么参数不能全部初始化成一样？

> 所属专题：[模型生命周期](./01-一个大模型到底是怎么诞生的.md) → **参数初始化与对称性** → [训练](./18-训练和推理有什么区别.md)
>
> 扩展路线：理解[参数](./06-参数到底是什么.md)和[模型架构](./02-模型架构是什么.md)后再读；本篇不进入 32 篇主路线。

常见问题是“第一步出生是啥意思”，答案提到：代码会先创建模型结构，再给参数初值。另一个问题又把追问推进了一步：**神经网络的权重能不能全部从同一个值开始？**

问题不只在“全 0”这个数字。假如同一层里本来应该分工的计算单元拥有完全相同的连接、初值和更新信号，它们会一直做相同的事。训练看似在更新许多参数，实际没有让这些位置学出不同功能。随机初始化首先要打破的，就是这种对称性。

## 两个单元为什么会一直一样

想象某一层有两个结构相同的计算单元。它们接收同一份输入，使用相同权重和偏置，再把结果送到下一层：

```text
同一份输入 x
   ├─ 相同权重 w、偏置 b → 单元 1 → 相同方式参与输出
   └─ 相同权重 w、偏置 b → 单元 2 → 相同方式参与输出
```

前向计算时，两边的结果相同。反向传播时，如果后续连接也没有区别，两边收到的梯度也相同。优化器于是给它们加上同样的改变量：

```text
相同初值 + 相同梯度更新 = 更新后仍然相同
```

这张图想帮你看懂“对称”为什么会自己保持。读图时最重要的是：训练不会凭空知道“单元 1 应该学语法，单元 2 应该学格式”；两条计算路径若完全不可区分，梯度下降也会同等对待它们。

把同一层做得很宽，本来是希望不同位置学习不同特征。若一百个单元始终产生同样的值，它们提供的有效自由度就远小于参数数量。模型并非一定完全不能更新，但大量重复位置无法形成预期分工。

## 全 0 还会带来更直接的梯度问题

在多层网络中，某层梯度通常会乘上后续层的权重再向前传播。如果所有相关权重都是 0，这个乘积可能把传回前层的信号也变成 0。靠近输出的一层或许先得到非零更新，前面的层却可能暂时收不到学习信号。

具体表现取决于架构、激活函数、损失和哪些位置被设为 0，因此“全 0 后每个参数永远都不动”并不是对所有模型都成立的通用定理。可靠的结论是：**把需要学习不同表示的权重全部设成同一个值，会保留不必要的对称性；全 0 还可能阻断深层网络的梯度传播。**

这也解释了为什么逻辑回归等没有隐藏单元分工问题的简单模型，有时可以从 0 开始；不能把它的经验直接搬到多层神经网络。

## 为什么偏置常常可以是 0

“参数不能全为 0”经常被误读成“模型里的每一个数都必须随机”。实际初始化通常按参数职责分别处理。

线性层的权重矩阵若已经随机且不对称，即使同层偏置都从 0 开始，不同单元的输入加权结果仍然不同，对称性已经被权重打破。类似地，归一化层的缩放参数常从 1 开始、偏移参数常从 0 开始；这些相同初值是架构设计的一部分，不代表整个模型对称。

判断重点不是单独看某一组数有没有重复，而是问：本来需要分工的完整计算路径，是否仍能被区分？

## 随机也不能随便填

只要数字不同就够了吗？不够。初值过大，信号经过很多层后可能迅速放大，激活或梯度变得不稳定；初值过小，信号可能逐层衰减，前面几层几乎学不到东西。

Xavier / Glorot 初始化会根据一层的输入与输出宽度选择尺度，目标是让信号和梯度在层间传播时不要剧烈放大或缩小。He / Kaiming 初始化进一步考虑 ReLU 一类激活函数只保留部分信号的特点。它们不是在给模型“预装知识”，而是在为优化创造更合适的数值起点。

现代 Transformer 的初始化还会考虑残差连接、层数、注意力与前馈模块的结构。有的实现对特定输出投影额外缩放，有的使用截断正态分布，也有模型从已有 Checkpoint 继续训练。看到“随机初始化”四个字，不能推出所有张量都来自同一个均匀分布。

## 随机种子为什么仍然重要

随机初值不编码训练语料里的知识，但这不表示随机起点“完全不重要”。不同随机种子会改变初值、数据顺序、Dropout 等过程，训练可能进入不同优化路径，最终参数和评测结果也可能不同。

在大规模训练中，团队会记录随机种子、框架版本、硬件与分布式设置，并通过多次小规模实验检查稳定性。即使种子相同，某些并行算子和硬件执行顺序也可能使结果无法逐位复现。随机性不是模型能力的来源，却是实验不确定性的一部分。

预训练模型的使用者通常不会重新随机初始化全部权重；他们加载已经训练好的文件。若做微调，新加的分类头或适配模块可能需要初始化，而底座权重从 Checkpoint 恢复。误把“初始化模型”和“加载模型”当成一件事，会把已经学到的参数覆盖掉。

## 把三个追问收回来

**为什么不能把所有权重设成 0？** 需要分工的单元会处于相同状态并收到相同更新，深层网络的梯度还可能被零权重阻断，模型无法充分利用这些参数。

**全部设成同一个非零小数可以吗？** 通常仍不行。问题是相同计算路径保持对称，不只是哪一个具体数值。

**偏置为 0、归一化缩放为 1，为什么没事？** 因为其他权重已经打破完整路径的对称性，而这些固定初值符合相应模块的职责。初始化必须按结构分析，不能要求所有参数都不同。

**随机起点训练久了就完全没影响吗？** 不能保证。训练会用数据大幅重塑参数，但初值和其他随机过程仍会影响稳定性、收敛路径与复现实验。
