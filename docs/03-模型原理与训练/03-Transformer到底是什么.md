# Transformer 到底是什么？

“Transformer 是什么”很容易得到一句循环解释：大语言模型用 Transformer，而 Transformer 是大语言模型的架构。读完仍然不知道它内部做了什么，也不知道它是框架、算法、一个具体模型，还是 Attention 的英文别名。

关于“架构、层数、宽度、专家是不是框架自带”已经把问题推到这里。要真正接住它，我们需要打开一层 Transformer，看一串 Token 怎样交换信息、各自变换，再把结果交给下一层。

## 它是一类序列模型架构

Transformer 是一种神经网络[架构](./02-模型架构是什么.md)。它规定怎样把序列位置表示成向量，怎样让不同位置交换信息，怎样在每个位置继续做非线性变换，以及怎样通过残差连接和归一化堆叠很多层。

2017 年论文 *Attention Is All You Need* 首先为机器翻译提出了 Transformer。原始结构包含读取输入的 Encoder（编码器）和逐步产生目标序列的 Decoder（解码器）。后来的语言模型沿用并改造了这套架构，出现只使用编码器、只使用解码器以及保留编码器—解码器的不同家族。

所以 Transformer 不是某个模型文件。多个模型可以采用 Transformer 思想，却有不同层数、宽度、位置方法、Attention 变体、训练数据和参数；它们的能力与成本不会因为架构名称相同就自动一样。

## 一层 Transformer 不只有 Attention

这张图想帮你建立一层内部的最小地图。为了零基础可读，它省略了多头细节、矩阵形状和不同变体中的先后差异。

```text
每个 Token 的当前表示 + 位置信息
              ↓
Self-Attention：从其他位置汇总相关信息
              ↓
残差连接与归一化
              ↓
前馈网络：每个位置各自继续变换
              ↓
残差连接与归一化
              ↓
交给下一层
```

读图时最重要的是两类计算交替出现：Attention 负责位置之间的信息交换，前馈网络负责对每个位置的表示继续加工。残差连接为原有信息提供短路径，归一化帮助控制训练中的数值行为。具体模型可能采用 Pre-Norm、Post-Norm、并行子层或其他变体，不能把这张简图当成所有 Transformer 的逐行代码。

[Attention](./05-Attention到底是什么.md)虽然出现在论文标题中，却只是架构的核心组件之一。把 Transformer 说成“就是注意力”会漏掉前馈网络、位置处理、残差、归一化、输出层以及大量具体配置。

## Self-Attention 让一个位置读取其他位置

看一句话：

> 小王把书递给小李，因为他已经看完了。

处理“他”这个位置时，模型需要结合“小王”“小李”“书”“看完”等其他位置的信息。Self-Attention 会根据各位置当前表示计算关联权重，再把相关位置的内容按权重组合回来。它不是从词典里直接查出代词答案，而是在当前序列和训练所得参数下进行数值计算。

“Self”表示 Query、Key、Value 都来自同一序列的表示，不是说模型在自我反思。多头注意力会并行使用多组投影，让不同头有机会捕捉不同关系；但不能保证某个头永远只负责语法、另一个永远只负责事实，实际表示往往更分散。

完整 Query、Key、Value 和权重计算会在 Attention 主页面讲。此处先保留架构层直觉：在进入下一层前，每个 Token 位置都能把其他允许访问的位置的信息汇入自己的新表示。

## 位置信息解决“同样的词，不同的顺序”

如果只把一组 Token 交给没有位置信息的 Self-Attention，“猫追狗”和“狗追猫”会难以区分顺序。Transformer 因此需要某种位置表示，把第几个位置以及位置之间的关系带入计算。

原因在于，普通 Self-Attention 对每个位置使用同样的投影和配对计算。若只交换输入位置、又没有任何位置线索，输出也主要只是跟着交换；计算知道“有哪些表示”，却没有独立信号说明谁在第 1 位、谁在第 2 位。位置编码或相对位置机制把顺序加入表示或注意力分数，模型才有材料学习先后、距离和方向。

原始论文使用正弦、余弦位置编码；后续模型发展出可学习位置嵌入、旋转位置编码和相对位置等多种方案。它们都在解决顺序问题，具体可支持多长序列、能否外推和怎样影响 Attention 则各不相同。

这也说明上下文窗口不是一个与架构无关的产品数字。模型的位置方法、训练长度、Attention 实现和服务配置会一起影响可处理序列长度；把软件界面里的“长对话”能力全部归功于参数量并不准确。

## 前馈网络让每个位置继续变换

Attention 汇总其他位置的信息后，每个位置还会经过前馈网络（Feed-Forward Network，FFN）。它通常包含两次线性变换和中间非线性激活，可以把表示投到更宽的内部空间再压回主维度。

这个模块在许多 Transformer 中占有大量参数和计算。混合专家模型常把普通前馈网络替换为多个专家前馈网络，再由路由器为 Token 选择少数专家。因此，“专家”与 Transformer 并不冲突，它是对架构中某个子模块的扩展方式。

Attention 负责“从哪里取信息”，前馈网络可以粗略理解为“拿到信息后怎样在当前位置继续变换”。这只是职责直觉，真实计算相互依赖，不能把一层能力机械拆成两个独立人类部门。

## 残差连接为什么重要

如果每层都完全覆盖上一层表示，深层网络中的信息和梯度会更难稳定传播。残差连接把子模块输入直接加到输出上，让新计算像是在原表示基础上做增量修改，也为信息提供跨过子模块的短路径。

归一化则调整表示的数值尺度，帮助深层训练稳定。原始论文与现代模型在归一化放在子层之前还是之后等细节上可能不同；这些看似小的结构选择，会影响可训练深度和数值行为。

因此，看到“一个模型有 80 层 Transformer”时，不应把每层想成只有一次 Attention。每层包含多个带参数的子模块和连接，层与层还可能采用共享、稀疏或其他变化。

## Encoder、Decoder 和 Decoder-only 是三种什么用法

原始 Transformer 为翻译设计：Encoder 读取源语言序列，形成上下文表示；Decoder 一边读取 Encoder 结果，一边根据已经生成的目标 Token 预测下一步。Decoder 的自注意力会使用遮罩，避免训练时偷看尚未生成的未来位置。

后来常见的结构可以粗分为：

- Encoder-only：重点为输入各位置生成上下文表示，常用于分类、检索表示等理解任务；
- Decoder-only：只允许每个位置使用当前及之前的信息，适合自回归续写，许多生成式 LLM 采用这一路线；
- Encoder–Decoder：先编码输入，再由解码器生成另一段序列，翻译与文本到文本任务中常见。

这是一种教学分类，不代表每类模型内部完全相同。“GPT 是 Decoder-only Transformer”说明它采用的结构路线，不能据此推出具体参数量、训练数据、工具或产品功能。

## 并行训练和逐 Token 生成并不矛盾

在循环神经网络中，后一个位置的隐藏状态通常依赖前一个位置的计算结果，序列内部很难完全并行。Transformer 训练时可以同时计算一段已知序列中许多位置的表示，再用遮罩保证每个位置只使用允许的前文。这让现代硬件更容易批量执行矩阵运算。

但生成新文本时，未来 Token 还不存在。模型必须先生成第一个新 Token，把它接回上下文，才能计算第二个；因此自回归推理仍然逐步进行。KV Cache 可以避免每一步重新计算全部历史的部分中间结果，却不能让未知的后续 Token 提前出现。

```text
训练：整段正确序列已知 → 多个位置可并行计算训练目标

生成：下一个 Token 未知 → 生成一个 → 接回去 → 再生成一个
```

这张对比想解决一个常见矛盾：Transformer 让训练更易并行，不等于一次生成整段回答。读图时要区分训练数据中的已知目标与推理时尚未产生的未来。

## 为什么 LLM 经常使用 Transformer

Transformer 能用 Attention 建立远距离位置关系，训练时又适合在 GPU 等硬件上进行大规模矩阵并行；架构还可以通过堆叠层数、扩大宽度和改造子模块扩展到很大规模。这些特性使它成为现代语言模型的重要基础。

但“使用 Transformer”不是成功保证。数据、训练目标、优化、参数规模、后训练和系统工具都会影响最终表现。Transformer 也不只用于语言，视觉、语音、蛋白质和多模态任务都发展出了相应变体。

它还有明确成本。标准全注意力需要处理许多位置对，序列变长时计算和内存需求快速增加；上下文窗口、位置表示和推理缓存也带来工程边界。长上下文模型常通过高效算子、稀疏或局部注意力等方法缓解成本，但每种方法都有自己的质量与实现权衡。

## 把几个容易混的词归位

**Transformer 是架构，不是框架。** PyTorch、JAX 等框架用来实现和运行它。

**Transformer 不是某一个 LLM。** 不同模型家族可以采用不同 Transformer 配置和训练结果。

**Transformer 不等于 Attention。** Attention 是组件，架构还包含前馈网络、位置、残差和归一化等。

**Transformer 不等于 GPT。** [GPT](../01-AI与大模型/05-GPT和ChatGPT有什么区别.md) 是采用 Transformer 路线的具体模型家族。

**GPT 是 Transformer 本身吗？** 不是。Transformer 是架构家族；GPT 是采用 Decoder-only Transformer 路线、再由具体配置和训练过程得到的一系列模型。其他模型也能采用 Transformer。

**Attention 为什么还要位置编码？** 不带位置线索的 Self-Attention 没有独立的序列顺序信号。位置机制让模型区分先后与距离，不代表所有模型都使用原论文同一种正弦编码。

**Encoder-only、Encoder–Decoder 和 Decoder-only 怎样区分？** 主要看信息可见方式和输出任务：编码器通常同时读取输入两侧，解码器用因果遮罩逐步生成，编码器—解码器先读完整输入再生成目标序列。

**Transformer 也不代表无限上下文。** 每个模型都有训练和实现所支持的序列边界，窗口更大也不保证每个位置都被可靠使用。

## 回到最初的问题

Transformer 是一类处理序列的神经网络架构。它让序列位置通过 Attention 汇总信息，再用前馈网络变换每个位置，并借助位置表示、残差和归一化堆叠成深层模型。

LLM 经常提到它，是因为这套结构适合学习语言序列关系、进行大规模并行训练和扩展模型规模。它仍只是“模型怎样算”的设计层，不是训练框架、单一模型、聊天产品或全部 AI。
