# 参数到底是什么？

> Level: `Core` · Path: `Main`

## 读完你应该明白

1. 参数是模型内部能通过训练调整的数值。
2. 参数会共同参与计算，不是一条参数对应一条知识。
3. 参数、训练数据、超参数和运行中的中间结果不是一回事。
4. 参数量不能单独决定模型能力。

## 一个小白真的会怎么问？

> 参数最后体现成什么？
>
> 这些数字为什么最后能让模型做事？
>
> 1.5B 参数是不是 15 亿条训练数据？

## 先说人话

参数（Parameter）可以先理解成模型内部大量**可以通过训练调节的数字**。

输入进入模型后，这些数字会影响信息怎样被放大、减弱和组合，最后影响模型输出。

把参数类比成许多“可调旋钮”有助于形成直觉，但这不是严格定义。真实参数通常以数组形式参与数学运算，并不是一排可以让人逐个拧动的实体旋钮。

## 举个极简例子

假设一个估价模型只看房屋面积：

```text
房屋面积
   ↓
乘以一个可调整的数值
   ↓
加上另一个可调整的数值
   ↓
预测价格
```

这里“乘以多少”和“最后加多少”就是模型参数。训练会利用已知成交记录，逐步调整它们，让预测更接近实际价格。

真实大模型的结构复杂得多，参数通常按矩阵等多维数组组织，并在许多层中共同参与计算，但“训练负责调整、推理负责使用”这一点相通。

## 严格来说

参数是模型中由训练过程学习或调整的数值变量。常见参数包括权重（Weight）和偏置（Bias）。

在深度学习框架里，许多参数会组织成张量（Tensor）——可以先把张量理解为一组按一个或多个维度排列的数字。

```text
模型结构
   +
具有特定形状的参数张量
   +
规定好的计算过程
   ↓
输入被转换成输出
```

模型结构决定哪些地方需要参数以及这些参数怎样参与计算；训练再为这些位置找到具体数值。

## 参数是怎么变化的？

训练时可以先用下面的流程理解：

```text
给模型一批训练样本
        ↓
模型用当前参数计算结果
        ↓
计算结果与训练目标相差多少
        ↓
训练算法判断参数应往哪个方向调整
        ↓
小幅更新参数
        ↓
重复很多次
```

这里的“相差多少”通常由损失函数（Loss Function）计算；参数如何调整会在训练章节详细说明。

训练结束后，部署中的普通推理通常读取并使用这些参数，而不会因为每次聊天自动修改它们。

## 参数最后是什么形式？

在运行时，参数通常是内存或显存中的数值张量。保存到磁盘时，它们通常成为权重文件或训练状态保存点（Checkpoint）的一部分。

一个可用模型落盘后可能还需要：

- 描述模型结构的配置；
- 权重或 Checkpoint 文件；
- 把文本转换成 Token 的 Tokenizer 配置和词表；
- 运行所需的其他元数据。

因此，“模型参数是数字”是正确的第一层理解；“整个模型就只是一个装数字的文件”则过于简单。

## 几个数字为什么能形成能力？

单独看一个参数通常很难解释成“它记住了北京是中国首都”或“它负责写代码”。

模型的行为来自：

```text
结构规定的计算方式
       +
大量参数之间的组合
       +
输入在多层计算中的变化
       ↓
最终输出
```

训练会让大量参数共同形成对语言模式的分布式表示。“分布式”表示信息通常分散在许多参数及其相互作用中，而不是每条事实独占一个位置。

至于预测下一个 Token 为什么能形成较广泛能力，需要结合训练目标、数据与泛化继续解释，不能只归因于“参数多”。

## 最容易搞混的东西

### 参数 ≠ 训练数据

```text
训练数据：训练时提供的样本和信号
参数：模型从训练过程中调整出的内部数值
```

数据不会简单地逐条变成参数。两者的数量单位有时都使用 B、T 等缩写，但所计数的对象不同。

### 参数 ≠ 超参数

超参数（Hyperparameter）是训练或结构配置，例如学习率、层数或批次大小。它们通常由开发者选择或搜索，而不是和普通权重一样由一次训练直接学出。

### 参数 ≠ 神经元数量

一个计算单元可能连接许多权重，还可能有偏置等参数。参数量不能直接当作“神经元数量”。

### 参数 ≠ Context 或缓存

参数来自训练并在推理中被使用；Context 是当前请求提供给模型的信息；缓存保存运行过程中的可复用中间结果。它们的生命周期和作用不同。

## 常见误区

### 误区 1：一个参数保存一条知识

通常不对。模型的知识和能力往往由大量参数共同编码，也可能存在记忆训练片段等复杂现象。

### 误区 2：参数越多就一定越聪明

不对。参数量影响模型可表达的计算规模与运行成本，但架构、数据、训练方法、后训练和任务都会影响能力。

### 误区 3：使用模型时参数会不断学习

普通推理通常不会更新训练参数。产品保存对话、建立 Memory 或把资料放进 Context，也不等于模型参数发生了训练更新。

## 为什么我要知道它？

参数连接了模型生命周期的多个阶段：

```text
设计结构 → 确定参数形状和数量
训练       → 调整参数
保存       → 把参数写入权重 / Checkpoint
部署       → 加载参数
推理       → 使用参数计算输出
```

分清参数后，才能继续理解参数量、训练数据、显存占用、量化和微调。

## 你只需要记住

1. 参数是模型内部由训练调整、在推理中参与计算的数值。
2. 参数通常组织成张量，权重和偏置是常见参数。
3. 模型能力来自结构与大量参数的共同作用，不是一条参数对应一条知识。
4. 参数量不能单独决定模型能力。
