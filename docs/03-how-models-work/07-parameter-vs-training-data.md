# 参数量和训练数据有什么区别？

> Level: `Core` · Path: `Main`

## 读完你应该明白

1. 参数属于模型内部，训练数据是训练时使用的样本。
2. 参数数量和 Token 数量不能互相换算。
3. 模型规模、数据与计算预算需要合理配合。
4. 不能只凭参数量判断模型能力。

## 一个小白真的会怎么问？

> 参数量就是训练数据吗？
>
> 1.5B 模型是不是表示它读了 15 亿条数据？
>
> 参数越多，是不是能装下越多资料？

## 先说人话

参数和训练数据是两类不同东西：

```text
训练数据：模型学习时接触的样本
参数：训练过程中被调整的模型内部数值
```

训练数据影响参数怎样变化，但不会一条数据直接变成一个参数。

## 举个例子

训练一个垃圾邮件模型时，我们可以准备许多已标注邮件。邮件和标签属于训练数据。

模型读入这些样本，计算预测并根据误差调整内部权重。训练结束后留下来参与新邮件判断的权重属于参数。

```text
训练邮件
   ↓ 提供学习信号
训练过程
   ↓ 调整数值
模型参数
   ↓ 用于新输入
分类结果
```

## 严格来说

训练数据（Training Data）是训练过程使用的输入、目标或其他反馈信号。它可以是文字、图片、音频、代码、标签、偏好比较等。

参数（Parameter）是模型内部由训练过程学习或调整的数值变量。完整解释见：[参数到底是什么](./06-parameter.md)。

两者通过训练算法发生联系：算法根据模型在训练数据上的表现，计算参数应该怎样更新。

## 为什么两边都用 B、T？

`K`、`M`、`B`、`T` 只是数量级缩写：

```text
K = thousand = 千
M = million  = 百万
B = billion  = 十亿
T = trillion = 万亿
```

关键是看它们在数什么：

```text
7B parameters  → 约 70 亿个参数
7B tokens      → 约 70 亿个 Token
```

数字相同不代表对象相同，就像“100 本书”和“100 个书架”不能因为都是 100 就画等号。

## 参数和数据怎么配合？

模型太小，可能没有足够能力表示任务所需的复杂规律；模型很大但有效数据或训练计算不足，也可能没有被充分训练。

```text
模型规模
   +
数据数量与质量
   +
训练计算预算
   +
训练方法
   ↓
共同影响结果
```

研究者会用 Scaling Laws（规模定律）研究模型、数据和计算量怎样共同影响训练效果。不同研究结论依赖模型、数据、目标和实验条件，不存在适用于所有模型的永久固定比例。

## 最容易搞混的东西

### 参数量 ≠ 数据量

参数量数模型内部可训练数值，数据量数训练样本、字节或 Token。两者没有直接换算公式。

### 训练数据 ≠ Context

训练数据在训练阶段影响参数；Context 是推理时当前一次计算可以使用的信息。把资料粘贴到聊天中不会自动把它变成训练数据。

### 参数 ≠ 知识条目

不能把一个参数理解成一条事实。模型的知识和能力通常分布在许多参数共同实现的计算模式中。

### 数据多 ≠ 数据好

重复、错误、偏见或与目标无关的数据也会影响训练。数量只是一个维度，数据质量和组成同样重要。

## 常见误区

### 误区 1：参数像硬盘，数据会被逐条存进去

这个类比容易留下错误心智模型。训练会根据数据反复调整参数，但模型通常不是可逐条查询原始资料的存储设备。

### 误区 2：参数越多一定越聪明

模型能力还受架构、数据、训练目标、计算预算、后训练和评估任务影响。

### 误区 3：训练数据越多一定越好

更多有效数据可能有帮助，但低质量、重复或不匹配的数据并不自动提升能力；训练是否充分还受计算预算限制。

## 为什么我要知道它？

看模型报告时，你会同时见到“多少 B 参数”和“训练了多少 T Token”。如果不分清计数对象，就会误读模型规模、训练成本和能力来源。

## 你只需要记住

1. 训练数据是学习材料，参数是训练调整出的模型内部数值；这个“材料”类比不表示数据被原样装进参数。
2. Parameter 和 Token 都可用 B、T 计数，但不能互相换算。
3. 模型规模、数据、计算预算和训练方法共同影响结果。
4. 参数多或数据多都不保证模型一定更好。
