# Hallucination（幻觉）是什么？

> Level: `Core` · Path: `Main`

## 一个小白真的会怎么问？

> 为什么 AI 不知道答案时，不直接说不知道？
>
> 它为什么能把错误内容说得那么像真的？

## 先说人话

Hallucination（幻觉）通常指生成模型产出看似合理，却与事实不符，或缺少给定来源与任务条件支持的内容。

它可能是错误日期、虚构人物、并不存在的引用，也可能是在总结资料时加入原文没有支持的细节。

## 举个例子

你让模型只根据一份会议记录总结决定，记录里写的是：

```text
下周继续讨论上线日期。
```

模型却总结成：

```text
团队决定下周五正式上线。
```

“下周五正式上线”听起来顺畅，但来源没有支持。这就是与给定资料不一致的幻觉。

如果模型回答一个常识问题时编出不存在的事实，则更侧重事实正确性问题。

## 严格来说

不同任务对 Hallucination 的具体定义不完全相同，常见判断至少包含两条轴：

```text
Factuality（事实性）
输出是否符合可核验的外部事实

Faithfulness（忠实性）
输出是否受到当前提供的来源或输入支持
```

一句话可能符合现实事实，却没有被题目指定的资料支持；也可能忠实复述了一份本身就写错的资料。因此，评估前要先说明“相对于什么判断”。

## 为什么模型会产生幻觉？

没有一个原因可以解释所有幻觉。常见因素包括：

- 训练数据包含错误、冲突、缺失或过时信息；
- 训练目标鼓励生成符合上下文规律的后续 Token，不等于逐句执行事实核验；
- 参数中的模式不保证能稳定、完整地取出特定事实；
- 模型可能没有正确利用 Prompt 或检索到的资料；
- 生成策略会在多个候选 Token 之间选择，错误可能逐步累积；
- 问题本身含糊、前提错误或要求模型猜测未知信息。

```text
不完整或冲突的信息
       +
生成式预测目标
       +
Context 使用与生成误差
       ↓
可能产生流畅但无依据的内容
```

## 为什么它听起来还很自信？

语言模型擅长生成在语言上连贯的文本。语气是否坚定，也是输出的文本模式，不是一个可靠的“事实置信度仪表”。

因此：

```text
表达流畅 ≠ 事实正确
语气确定 ≠ 证据充分
附带链接 ≠ 引用真实且支持结论
```

## 幻觉是模型在撒谎吗？

“撒谎”通常意味着知道真相并有意欺骗。仅凭错误输出，不能证明模型具有这种意图。

更准确的说法是：系统生成了错误或缺乏依据的内容。把它称为“幻觉”是技术语境中的简称，不表示模型拥有人的感知体验。

## 能不能减少幻觉？

可以降低风险，但没有一种方法适用于所有场景并保证清零：

- 改进数据、训练与后训练；
- 让模型在证据不足时明确不确定或拒答；
- 用搜索、数据库或 RAG 提供相关资料；
- 要求输出引用，并检查引用是否真实支持主张；
- 用规则、计算器、代码或专用系统验证可确定结果；
- 在高风险场景加入领域专家审核。

外部资料也可能错误，检索可能找错，模型还可能误读资料。因此，“联网了”或“用了 RAG”不等于幻觉已经消失。

## 最容易搞混的东西

### Hallucination ≠ 任何不喜欢的答案

文风不合适、回答不够详细或观点不同，不一定是幻觉。需要指出具体事实、来源或任务约束上的不一致。

### Hallucination ≠ 过时信息

过时信息会造成错误，但也可能来自旧数据、缓存或外部资料。排查时要找到具体来源，不能把所有错误都归到模型本身。

### Hallucination ≠ 随机性

生成随机性可能让不同回答出现不同错误，但即使固定生成设置，模型也可能稳定地产生同一个错误。

## 常见误区

### 误区 1：模型越大，就一定不会幻觉

不对。规模会影响许多能力，但事实可靠性还受数据、训练、任务、Context、工具与验证流程影响。

### 误区 2：让模型“不要编”就够了

清晰指令可能有帮助，却不能为模型补上未知事实，也不能替代外部证据。

### 误区 3：引用看起来专业，就可以相信

模型可能编造标题、作者、网址或让真实引用与结论不匹配。引用必须打开并逐项核对。

## 为什么我要知道它？

幻觉决定了生成式 AI 的使用边界。写作灵感和高风险事实判断需要不同的可靠性标准；医疗、法律、财务、生产操作等场景不能只凭一段流畅回答行动。

理解幻觉后，下一步不是停止使用模型，而是把任务拆成“可以生成”和“必须验证”的部分。

## 你只需要记住

1. Hallucination 是看似合理却与事实、来源或任务条件不一致的生成内容。
2. 流畅、自信和带引用都不自动等于正确。
3. 幻觉有多种来源，不应简单理解为模型故意撒谎。
4. 搜索、RAG、提示和训练可以降低部分风险，但不能保证彻底消除。
