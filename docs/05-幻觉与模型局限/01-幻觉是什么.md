# 幻觉是什么？

> 你现在的位置：[推理能力](../04-模型能力/03-推理能力是什么.md) → **幻觉** → [LLM 与数据库的边界](./02-为什么LLM不是数据库.md)
>
> 课程导航：[上一篇：推理能力是什么](../04-模型能力/03-推理能力是什么.md) · 第 21 / 32 篇 · [下一篇：为什么 LLM 不是数据库](./02-为什么LLM不是数据库.md)

原始聊天问得很直接：“幻觉是啥意思？”它不是 AI 真的看见了不存在的东西，也不等于所有错误回答。生成式 AI 语境中的幻觉（Hallucination），通常指系统生成了看似合理，却与外部事实、给定资料或任务约束不一致的内容。

它最麻烦的地方不是胡言乱语，而是能把虚构日期、不存在的论文、错误因果或资料中没有的细节，写成一段很顺畅的话。语言质量和事实可靠性是两条不同的轴。

## 同一句话可能有两种不同的问题

会议记录只写着“上线日期将在下周继续讨论”，模型却总结成“团队决定下周五上线”。“下周五”没有来源支持，这是对给定材料不忠实。

若模型回答“某药已获监管机构批准”，但官方数据库并无这项记录，这是外部事实错误。研究和评测里常把两条轴分开：

| 判断角度 | 要问的问题 | 例子 |
|---|---|---|
| 事实性（Factuality） | 是否符合可核验的现实事实？ | 产品发布日期是否正确 |
| 忠实性（Faithfulness） | 是否能由当前来源或输入推出？ | 总结有没有加入原文未说的决定 |

一段话可能符合现实，却没有被指定材料支持；也可能忠实复述了一份本身就错误的资料。判断幻觉前，要先说明“相对于什么证据”。

## 模型为什么不直接说“不知道”

[下一 Token 预测](../03-模型原理与训练/10-为什么预测下一个Token能学到能力.md)训练模型生成符合上下文规律的后续内容，它不自带一个能逐句查询世界真假的裁判。数据中若存在错误、冲突、过时信息或知识空白，参数形成的模式也会受到影响。

推理时，模型还要根据有限上下文逐步生成。问题含糊、前提错误、检索资料不相关、早期 Token 走偏或采样选择不佳，都可能让后续内容沿着错误方向继续。后训练可以鼓励拒答和表达不确定，但“何时真的不知道”本身也需要判断，无法靠一句系统提示彻底解决。

```text
训练数据中的缺失、冲突或过时内容
              +
生成目标不等于事实核验目标
              +
当前问题、上下文、检索与生成误差
              ↓
流畅但缺少事实或来源支持的输出
```

这张图想说明幻觉不是单一故障。读图时注意三层都可能贡献错误：模型参数、当前输入与资料、生成和产品流程；排查时不能一律归因于“模型太小”。

## 为什么错误听起来很自信

坚定或犹豫的语气也是 Token 序列。模型可以学会“根据研究表明”“确定无疑”这样的表达模式，却没有一个永远校准准确的内部仪表，把语气强度自动绑定到事实正确率。

同理，格式专业、推导很长、引用像真的，都只是需要进一步检查的输出特征。真实论文也可能不支持当前结论；一个能打开的链接可能指向无关页面；同一错误还可能在多次提问中稳定复现。

把幻觉说成“撒谎”也不准确。撒谎通常意味着知道真相并有意欺骗，仅凭错误文本无法证明这种意图。更可操作的描述是：系统输出了具体哪条无依据主张，以及验证过程怎样发现它。

## 联网、RAG 和温度能解决吗

外部搜索或 RAG 可以把更新、可引用的资料放进上下文，降低模型只依靠参数回忆的压力。但检索可能漏掉关键文档、返回过时页面或选错片段；模型也可能忽略、误读甚至曲解正确资料。所以“已经联网”不等于“已经核验”。

降低温度通常让输出更稳定，可能减少某些随机偏离，却不能修正参数中稳定的错误。让模型重复回答或自我反思有时能暴露矛盾，也可能反复确认同一个假答案。

提示模型“不要编造、没有证据就说不知道”值得做，但它只是风险控制的一层。高风险事实仍需连接权威数据源、限制输出范围、检查引用、使用确定性工具，并在需要时由具备责任和专业能力的人审核。

## 幻觉是否能被彻底清零

对一个范围很窄、答案来自受控数据库的任务，可以通过约束查询、模板和验证器大幅降低生成错误。但开放世界问答包含不断变化的事实、含糊请求和未覆盖情形，很难证明所有未来输出都不会幻觉。

因此，目标应从口号“消灭幻觉”变成可测量的风险管理：定义哪些错误最重要，建立测试集，记录引用支持率和关键事实错误率，对拒答与漏答也做权衡，持续监控上线后的新失败。

任务风险决定流程。写故事时虚构是目标，不叫幻觉；整理合同条款时擅自补一句则可能造成严重后果。不要用一个脱离场景的“幻觉率”覆盖所有用途。

## 把真实问题收回来

**幻觉到底是什么？** 是生成内容与外部事实、给定来源或任务约束不一致，却仍显得合理的现象；具体定义要随任务说明证据基准。

**为什么不知道时不直接说不知道？** 语言模型的核心生成目标不是知识库中的“未找到”查询。拒答能力需要训练、提示和系统规则，仍可能误判。

**RAG 已经给了正确资料，为什么还会答错？** 检索结果只是上下文；模型可能没有使用正确片段、混合参数记忆、误解关系或在生成时加入无支持内容。

**它是在故意撒谎吗？** 错误输出本身不足以证明意图。应关注可验证的错误和控制措施，而不是给系统套上人的心理状态。
