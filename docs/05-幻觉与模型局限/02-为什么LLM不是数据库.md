# 为什么 LLM 不是数据库？

> 你现在的位置：[幻觉](./01-幻觉是什么.md) → **LLM 与数据库边界** → [验证](./04-怎么验证AI的回答.md)
>
> 课程导航：[上一篇：幻觉是什么](./01-幻觉是什么.md) · 第 17 / 31 篇 · [下一篇：怎么验证 AI 的回答](./04-怎么验证AI的回答.md)

模型读过大量资料，又能回答知识题，很容易让人觉得“互联网被压缩进参数，提问就是查询”。公开社区甚至直接问：神经网络是不是一种软数据库？这个比喻能提醒我们参数确实携带从数据中学到的信息，但若把它当系统设计结论，就会犯危险错误。

**数据库保存并查询可定位的记录；LLM 使用训练得到的参数和当前上下文计算后续 Token。** 两者可以合作，却没有相同的更新、查询、一致性和审计保证。

## 查订单能看出最直接的区别

业务数据库里可以有一条记录：

```text
订单号：A1024
状态：已发货
更新时间：2026-08-18 10:30
```

程序按主键 `A1024` 查询，数据库定位记录并返回字段。状态改变后，可以更新这一行，使用事务和约束维护一致性，还能记录谁在什么时间修改了它。

LLM 参数里没有一个叫 `A1024` 的格子。若模型没有连接真实订单系统，它只能根据 Prompt、上下文和训练模式生成可能的回答；“已发货”听起来合理，也不代表当前业务事实。

```text
数据库：查询条件 → 定位记录 → 返回字段

LLM：上下文 + 参数 → 逐层计算 → 生成 Token
```

这张图比较的是核心工作方式。读图时注意，带数据库工具的 AI 产品会先让外部程序查询，再把结果交给模型；这是组合系统，不是底层模型突然变成数据库。

## “知识存在参数里”到底是什么意思

模型训练后，参数支持事实问答、语言使用和模式迁移，研究中常称为参数化知识（Parametric Knowledge）。这是功能性描述：改变或探测参数会影响模型能表达的知识。

它不表示“一条事实对应一组固定参数”。信息通常分布在许多数值和计算关系中，同一个参数会参与大量输入；同一事实换种问法，激活的计算路径也可能不同。我们无法像执行 `SELECT` 一样列出模型存了哪些完整记录。

模型也可能记住并复现训练片段，尤其是重复、独特或可识别的内容。但记忆部分文本仍不提供数据库保证：不能确认每条内容都保存，不能按字段完整枚举，不能逐条授权查询，也不能安全地把一条事实原地更新。

## 为什么知识会过时、冲突或换问法就变

参数反映某段训练过程。普通[推理](../03-模型原理与训练/18-训练和推理有什么区别.md)不会自动把今天的新事实写回模型。继续训练或编辑参数成本高，还可能影响其他行为。

训练数据本身可能来自不同日期和来源，包含互相冲突的说法。生成时，Prompt、上下文、采样和前面已经生成的 Token 都会影响后续结果。因此，模型能在一个问法下答对，在另一个问法下答错，也可能把两个相近实体的信息拼在一起。

数据库也可能存错数据，但它至少提供明确记录、查询语义和更新机制，便于定位问题。LLM 的[幻觉](./01-幻觉是什么.md)则可能生成一条从未存在于任何来源中的“记录”。

## 搜索、数据库、知识库和 LLM 各自负责什么

搜索引擎定位并排序外部页面；数据库按结构保存和操作记录；知识库组织某个范围内可管理的资料；LLM 擅长理解自然语言、转换表达和生成内容。真实产品常把这些组件串在一起。

```text
用户问题
  ↓ LLM 或程序理解意图
搜索 / 数据库 / 知识库执行检索
  ↓ 返回可追踪结果
LLM 组织为自然语言
  ↓
验证关键字段和引用
```

这张图想说明职责分工。读图时最重要的是，权威事实仍由外部数据源保存；模型负责交互和表达时，也可能误读结果，所以最后的验证没有消失。

RAG 就是常见组合：先检索相关资料，再把片段放进上下文让模型回答。它改善更新性和来源追踪，但检索会漏、资料会旧、模型会误解，不能自动获得数据库级一致性。

## 什么任务可以直接交给模型

改写文案、整理候选思路、把已提供材料转换成另一种表达，通常允许一定生成空间。若答案涉及订单状态、库存、价格、账户余额、法规版本或实时指标，应查询拥有该事实的系统。

即使接入数据库，也要控制权限、校验模型生成的查询、限制可执行操作，并把返回结果与用户权限绑定。模型说“我已取消订单”不代表操作真的执行；必须检查工具调用结果和业务状态。

系统设计可以采用一个朴素原则：**记录交给记录系统，计算交给确定性工具，语言理解与表达交给模型，关键结论交给验证流程。** 这不是降低 LLM 的价值，而是把它放在更可靠的位置。

## 回答真实问题

**神经网络是不是一种软数据库？** 作为“参数保留了数据中的信息”的宽松比喻可以使用；作为可寻址记录、精确查询、更新和一致性保证的数据库定义，不成立。

**模型学了大量资料，是不是把互联网原样装进参数？** 不是。训练会改变参数，形成分布式模式；模型可能记忆部分片段，却无法保证完整存储或逐条还原训练数据。

**参数越多，能存的事实就按比例增加吗？** 没有通用换算。参数量、架构、训练数据、优化和任务共同影响表现，参数也不是事实条目的计数器。

**接上数据库后，回答就一定正确吗？** 仍不一定。系统可能查错字段、权限不足、数据库本身过时，模型也可能错误转述。查询与最终表达都要留证据和错误处理。
