# 知识图谱和向量数据库有什么区别？

> 你现在的位置：[知识库](./02-知识库是什么.md) → **知识图谱与向量数据库** → [检索](./08-检索是什么.md)
>
> 所属专题：RAG 与知识系统 · 本文是 Optional 扩展阅读

Hacker News 的一场讨论直接把问题写在标题里：知识图谱和向量数据库，谁更能缓解 LLM 幻觉？评论里的答案是“两者都重要”，但这句话还缺少关键一步：它们保存什么，又分别适合回答什么问题？

向量数据库擅长按“意思像不像”寻找候选内容；知识图谱擅长保存“谁和谁以什么关系连接”。一个从相似性出发，一个从实体与明确关系出发。它们可以组合，却不能互相自动替代，更不能单独保证模型不出错。

## 用“哪个公司供应哪种芯片”看差别

文档中写着许多公司、产品和供应关系。向量方案会把文本片段转成 [Embedding](./03-Embedding是什么.md)，查询也转成向量，再找距离较近的片段。它很适合“找几段和芯片供应链相关的资料”，即使查询和原文没有使用完全相同的词。

知识图谱则先把信息整理成实体和边：

```text
[公司 A] --供应--> [芯片 X]
[芯片 X] --用于--> [产品 Y]
[公司 B] --收购--> [公司 A]
```

查询“公司 B 间接控制了哪些用于产品 Y 的芯片供应商”时，图可以沿明确关系多跳遍历。答案路径可以展示经过了哪些节点和边。

这张图想说明：向量保留的是可比较的数值表示，图谱显式保存实体与关系。前者的“接近”不等于事实关系，后者的一条边也必须有来源和时间范围。

## 向量数据库实际保存什么

[向量数据库](./05-向量数据库是什么.md)通常保存向量、原文或原文引用、文档与权限元数据，并提供近似最近邻搜索和过滤。它回答的是“哪些候选在当前表示空间里最相似”。

优势是入库门槛相对低：文档切片、生成 Embedding 后即可搜索；自然语言表达变化时仍可能召回相关片段。局限也来自相似性：型号、否定、时间和精确关系不一定因语义接近而被正确区分，返回的片段还要由后续系统核验。

## 知识图谱实际保存什么

知识图谱把人、组织、产品、地点等对象表示为实体，把供应、隶属、发布、位于等表示为有类型的关系，并可为它们保存属性、来源和时间。RDF 等标准使用主语—谓语—宾语形式表达事实；属性图则常把属性直接放在节点和边上。

它适合明确关系、多跳路径、依赖影响和可解释规则。例如“某依赖受漏洞影响的所有服务”需要沿依赖边遍历，而不仅是找描述相似的文档。

代价是建模与维护。实体名称要消歧，同一公司不同写法要合并；从文本自动抽取的关系可能错，Schema 会随业务变化；事实更新后旧边要失效。图中存在一条边不代表它天然正确。

## 它们不是两种互斥数据库产品

“图”和“向量”描述的是数据表示与查询能力，不一定对应两套独立基础设施。图数据库可以给节点保存向量并做相似搜索，关系型数据库也可能同时支持向量扩展；向量检索结果也可以作为图遍历的起点。

一种混合流程是：先用向量从大量文本中找候选实体和文档，再用知识图谱扩展邻居与多跳关系，最后把原始证据片段交给模型。另一个方向是先用图中的类型和权限缩小范围，再在候选节点内做向量相似搜索。

```text
自然语言问题
  ├─ 向量检索：找表达相近的文档与实体
  └─ 图查询：沿明确关系过滤和扩展
             ↓
      合并候选、回到原始证据
             ↓
         模型生成并引用
```

读图时注意最后仍要回到证据。图路径和相似片段只是检索结果，不能把模型抽取出的边再当成独立真相循环引用。

## 怎样选择

资料主要是自然语言、问题难以预先结构化、目标是找相关段落时，先做向量或关键词检索通常更直接。业务已经有明确实体、关系和规则，问题经常要求多跳、聚合与影响分析时，知识图谱更合适。

若团队还说不清要查询哪些关系，就不应为了“更高级”先建设庞大图谱；若精确关系决定业务结果，也不能只靠向量相似度。选择应由真实问题集驱动，再比较召回、关系正确率、来源可追溯、更新成本和权限执行。

权限同样不同。向量检索要在返回片段前过滤文档访问范围；图查询要同时限制节点、边和路径。先越权取回再要求模型“不提机密”，两种系统都不安全。

## 回答真实问题

**知识图谱和向量数据库谁更能减少幻觉？** 两者都只能改进证据获取。向量检索补充相似资料，图谱补充明确关系；最终还要验证来源、关系和生成是否忠实。

**知识图谱会取代向量数据库吗？** 不会普遍取代。它们解决的查询类型不同，也可在同一系统组合。

**GraphRAG 是把向量库换成图数据库吗？** 不一定。GraphRAG 是一类把图结构用于检索和组织证据的方法，具体实现可以同时使用图查询、向量检索和文本索引。
